# Genetic Toxicology Datasets & In Silico Models — Sourced Survey

Compiled 2026-10-10. Focus endpoints: bacterial reverse mutation (Ames), in vitro micronucleus (MNvit), TK6-cell micronucleus. Throughout, "open-source" = source code publicly available; "free to use" = usable at no cost without source access. Each fact carries its source URL, read date, and a `verified live` vs `index` flag.

## Summary

- **Ames data are abundant and public** (Hansen 6512, Bursi/Kazius ~4337/4204, NTP ~3070 assays, CCRIS & GENE-TOX now inside PubChem), but they **overlap heavily** (Hansen incorporates Kazius, CCRIS, GeneTox, VITIC...), so combined training sets risk duplication.
- **MNvit public curated sets are much smaller** (~894 compounds, Toxics 2023) and are scattered across literature; **no standalone public TK6 micronucleus dataset** was found (TK6 data exist within MNvit sets and in NTP's MultiFlow program).
- **Open-source predictors:** Toxtree (Benigni/Bossa alerts), lazar (read-across, GPL3), OPERA (MIT; but currently no genotox endpoint), AmesFormer / Poze-AMES / ames_gnn_mtl_network (GNNs for Ames). **Free-but-not-open:** VEGA (Ames consensus + IRFMN MN models), OECD QSAR Toolbox, ProTox-3.0, admetSAR, pkCSM, EPA TEST. **Commercial:** Derek Nexus, Sarah Nexus, Leadscope, CASE Ultra, ProtoTOX.

Notes on specific datasets:
- **Hansen 2009** is the de-facto Ames benchmark for ML; several GitHub mirrors exist (e.g., `datacleaning/Combined_2s_as_0s_publication.csv` in AmesFormer excludes proprietary Honma components). Overlaps Kazius/CCRIS/GeneTox by design — dedupe by InChIKey before merging with those sources.
- **AmesFormer dataset** (`combined.csv`): a "large, clean open-source Ames dataset" derived from public sources minus proprietary Honma data — https://github.com/luke-a-thompson/AmesFormer [index].
- **TDC AMES**: Therapeutics Data Commons hosts an AMES benchmark (used by ADMET-AI etc.) — noted but size/provenance not verified; flag.

## Caveats

1. **Dataset overlap / duplication.** Hansen 2009 deliberately aggregates Kazius, CCRIS, GeneTox, VITIC, Helma, Feng — merging these sources without InChIKey deduplication double-counts compounds and inflates apparent performance. AmesFormer ships a deduped public set.
2. **Label noise.** Inter-laboratory Ames reproducibility error is ~15% (Kazius 2005); model accuracy near 85% is effectively at the experimental ceiling.
3. **MN data concordance is poor across sources.** ISSMIC vs OASIS overlap: only 43% concordant calls (207 common compounds) — curate calls per guideline and document resolution rules (Toxics 2023 paper's approach is a good template).
4. **Applicability domain.** Most Ames models are trained on industrial chemicals (Hansen mean MW ~248); pharma-like space is under-represented (Novartis analysis). Check AD/reliability scores (VEGA gives low/moderate/high; OPERA gives AD + accuracy estimates).
5. **Toxtree micronucleus alerts are in vivo (rodent), not MNvit.** Don't use them as MNvit predictors. VEGA's IRFMN-VERMEER (in vitro MN) is the open/free option for MNvit.
6. **S9 / metabolic activation matters.** Datasets and models rarely resolve ±S9; urethane-type cases (in vivo MN positive, Ames negative) illustrate the gap.
7. **OPERA has no genotox endpoint** (verified live) — earlier confusion traced to EPA TEST docs (a different free tool that does include Ames).
